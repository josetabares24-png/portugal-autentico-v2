# Visitor Impact — mapa fuente → página

Actualizado: **2026-09-23**

Objetivo: convertir cambios externos en revisiones dirigidas. Este mapa no autoriza ediciones masivas.

## Regla operativa

**CAMBIO → FUENTE OFICIAL → PÁGINA REAL → HECHO VOLÁTIL → IMPACTO → ACCIÓN MÍNIMA → PRÓXIMA REVISIÓN**

Una fuente activa no implica que todas las páginas asociadas deban cambiar. Primero se busca una contradicción concreta.

## Clases de relación

- **DIRECTA** — la página publica el dato que la fuente puede invalidar.
- **CONTEXTUAL** — el cambio puede afectar el viaje descrito, pero no necesariamente contradice la página.
- **COMERCIAL** — el cambio puede volver incorrecto un ticket, CTA o producto afiliado.
- **PROTEGIDA** — página en observación/experimento; solo se corrige un hecho materialmente falso y se registra el confound.

## Cadencias por defecto

- cierres P0 sin fecha: semanal;
- obras o desvíos >=14 días: mensual o fecha de hito oficial;
- tarifas persistentes: al anunciar nueva tarifa;
- atracciones dinámicas con señal comercial: mensual;
- incidencias <14 días: fecha de expiración + 1 día para cerrar el registro.

## Criterio de éxito

Visitor Impact funciona si logra dos cosas a la vez:
1. evita que una página útil dé una instrucción materialmente falsa;
2. evita editar páginas que ya están correctas.

No se mide por número de actualizaciones publicadas.
