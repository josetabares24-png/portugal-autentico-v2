# Mapa editorial — Estaba en Lisboa

Actualizado: **2026-09-23**

Este mapa no es un menú nuevo ni autoriza crear siete páginas nuevas. Es la organización interna del contenido que ya existe para decidir enlazado, pilares, fusiones y futuros hubs.

## Regla

Cada artículo debe tener:
- una necesidad principal;
- una función dentro de un cluster;
- un siguiente paso lógico;
- una razón para seguir existiendo.

No crear un hub indexable hasta que el cluster tenga demanda suficiente y el hub resuelva algo distinto a listar enlaces.

## Huecos

No se declara ningún "NUEVO HUECO" como prioridad solo por intuición.

Un hueco entra en backlog únicamente si:
- Search Console muestra consultas sin destino adecuado;
- un cluster probado tiene una necesidad clara sin resolver;
- o investigación SERP demuestra una intención distinta.

## Siguiente uso de este mapa

1. medir clics internos con `select_content`;
2. identificar qué clusters consiguen continuación de lectura;
3. fortalecer enlaces entre pilar y soporte;
4. solo después decidir si alguno merece un hub público propio.
